# 🎬 IMDB Movie Review Sentiment Analysis

An end-to-end NLP sentiment analysis project trained on the **IMDB Movie Reviews** dataset using PyTorch and Hugging Face Transformers. This project addresses tricky sentiment edge cases—such as **negation** (*"not bad at all"*) and **contrastive phrasing** (*"starts off slow, but the second half is a triumph"*)—through targeted synthetic data augmentation and fine-tuning a pre-trained **DistilBERT** Transformer model.

---

## ✨ Key Features

- **Negation & Contrast Handling:** Augments the IMDB dataset with synthetic positive and negative negation/contrast examples so the model doesn't misclassify phrases like *"not bad"* or *"never boring"*.
- **Model Evolution:** Explored custom **Bidirectional LSTM (BiLSTM)** architectures before transitioning to a fine-tuned **`distilbert-base-uncased`** Transformer for deeper contextual understanding.
- **CPU-Friendly Fine-Tuning:** Configurable `MAX_TRAIN_SAMPLES`, `MAX_TEST_SAMPLES`, and `MAX_LEN` parameters to balance accuracy and training speed on CPU hardware.
- **Evaluation & Visualizations:** Generates test accuracy/loss metrics and saves training curves (`training_metrics.png`).
- **Interactive Web App:** Includes a **Streamlit** UI (`app.py`) with sample test buttons, confidence scores, and real-time sentiment prediction.

---
